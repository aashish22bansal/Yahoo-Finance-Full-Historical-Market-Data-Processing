Maven POM.xml Documentation

This document provides a detailed breakdown of the pom.xml file for the hadoop project. The POM (Project Object Model) is the fundamental unit of work in Maven. It is an XML file that contains information about the project and configuration details used by Maven to build the project.

Project Coordinates

Maven coordinates are a set of identifiers that uniquely define a project. They consist of a group ID, an artifact ID, and a version.

Group ID: com.aashish22bansal
Artifact ID: hadoop
Version: 0.0.1-SNAPSHOT
  • groupId: Typically identifies the organization or group that created the project.
  • artifactId: A unique name for the project's deliverable (e.g., the JAR or WAR file).
  • version: The specific release of the project. SNAPSHOT indicates a development version.

Dependencies

Dependencies are external libraries required by the project. Maven automatically downloads and manages these libraries.

Apache Hadoop Client

org.apache.hadoop:hadoop-client:3.1.1

This is a convenient aggregator dependency that pulls in the most common client-side libraries needed to interact with a Hadoop cluster, including those for HDFS, YARN, and MapReduce. It simplifies dependency management for applications that need to communicate with Hadoop.

Apache Hadoop Common

org.apache.hadoop:hadoop-common:3.3.6

Provides the fundamental utilities and libraries shared across all Hadoop components. It contains essential functionalities for I/O, configuration management, security, and the core APIs that HDFS, YARN, and MapReduce are built upon.

Exclusion: org.slf4j:slf4j-reload4j
This exclusion prevents Maven from including the slf4j-reload4j logging implementation. This is often done to avoid logging conflicts and allow the project to explicitly define its own logging framework (like Log4j or Logback).

Hadoop MapReduce Client Core

org.apache.hadoop:hadoop-mapreduce-client-core:3.3.6

This contains the core classes and interfaces essential for writing MapReduce applications. It provides the fundamental API for the MapReduce programming model (e.g., Mapper, Reducer classes) that developers use to create data processing jobs.

Exclusion: org.slf4j:slf4j-reload4j

Hadoop MapReduce Client JobClient

org.apache.hadoop:hadoop-mapreduce-client-jobclient:3.3.6

Provides the JobClient API, which is the primary interface for submitting MapReduce jobs to the cluster, monitoring their progress, and retrieving results and logs. It acts as the bridge between the user's application and the Hadoop cluster's resource manager.

Exclusion: org.slf4j:slf4j-reload4j

Hadoop HDFS Client

org.apache.hadoop:hadoop-hdfs-client:3.4.1

Contains the client-side libraries needed to interact programmatically with the Hadoop Distributed File System (HDFS). It allows the application to perform file operations like reading, writing, creating directories, and managing permissions on HDFS.

Apache Spark Core

org.apache.spark:spark-core_2.12:3.5.7

The foundation of the entire Spark platform. It provides the core execution engine, in-memory computing capabilities, and the primary programming abstraction: the Resilient Distributed Dataset (RDD). All other Spark libraries are built on top of Spark Core.

Apache Spark SQL

org.apache.spark:spark-sql_2.12:3.5.7

A Spark module for structured data processing. It introduces DataFrames and Datasets, which provide a higher-level API over RDDs, and allows for querying data via SQL. It includes a powerful optimizer (Catalyst) for high performance.

Apache Spark MLlib

org.apache.spark:spark-mllib_2.12:3.5.7

Spark's scalable machine learning library. It provides common ML algorithms for classification, regression, clustering, and collaborative filtering, as well as tools for building ML pipelines.

Apache Spark Connect

org.apache.spark:spark-connect_2.12:3.5.7

Enables a decoupled client-server architecture for Spark. It allows applications (from IDEs, notebooks, etc.) to connect to and interact with a remote Spark cluster using the DataFrame API, without embedding a full Spark driver.

Build Configuration

The <build> section defines how the project is built, including specifying plugins that perform tasks like compiling code and packaging deliverables.

Maven Compiler Plugin

org.apache.maven.plugins:maven-compiler-plugin:3.8.1

This plugin is responsible for compiling the Java source code (.java files) into bytecode (.class files). This POM has it configured to ensure the code is compatible with Java 1.8.

<configuration>
    <source>1.8</source>
    <target>1.8</target>
</configuration>
  • <source>1.8</source>: Tells the compiler that the source code is written in Java 8.
  • <target>1.8</target>: Instructs the compiler to generate bytecode that is compatible with a Java 8 JVM.

Note: This POM file lists two versions of the compiler plugin. Maven uses the more specific definition, so version 3.8.1 with the Java 1.8 configuration is the one that takes effect.

Maven Shade Plugin

org.apache.maven.plugins:maven-shade-plugin:3.4.1

This powerful plugin is used to create an "uber-JAR" (or "fat JAR"). An uber-JAR contains the project's own code plus all of its dependencies packaged into a single, executable file. This is extremely useful for Hadoop and Spark jobs, as it simplifies submitting the application to the cluster.

Configuration Details:

  • Goal: The shade goal is bound to the package phase, so the uber-JAR is created when you run mvn package.
  • <createDependencyReducedPom>false</createDependencyReducedPom>: Prevents the plugin from creating an additional, simplified POM file.
  • Transformers: Transformers modify files within the JAR during the shading process.
    • ManifestResourceTransformer: This transformer is used to create or modify the META-INF/MANIFEST.MF file inside the JAR. Here, it's configured to set the mainClass attribute, which makes the resulting JAR directly executable with java -jar ....
<configuration>
    <transformers>
        <transformer implementation="...">
            <mainClass>com.hadoop.example.WordCount</mainClass>
        </transformer>
    </transformers>
</configuration>
